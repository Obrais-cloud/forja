**What it is.** CLI Python para comparar respuestas de varios modelos Ollama locales lado-a-lado; streaming en paralelo, strip de <think>, fallback secuencial para modelos grandes, export markdown.

**When to reach for it.** Cuando dudas entre 3-4 modelos para una tarea concreta: mismo prompt, comparación visual + markdown para luego decidir.
