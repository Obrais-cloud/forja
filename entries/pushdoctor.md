**What it is.** Diagnose why a git push to GitHub will or won't work — credential helper, gh token validity, SSH key, and write-permission (viewerPermission) checks, with a verdict and copy-paste fixes.

**When to reach for it.** When a git push to GitHub fails or you want a preflight: tells you if it's the credential helper, an expired gh token, an unregistered SSH key, the wrong protocol, or that your account lacks write access. Single-file Python 3, stdlib only.
